# Visuales pendientes de evidencia

Este registro separa visuales que se pueden representar con información documentada de aquellos que no se deben dibujar ni presentar como evidencia hasta reunir insumos verificables.

## Evidencia audiovisual de entrevistas

| Campo | Detalle |
|---|---|
| Nombre | Registro audiovisual o captura autorizada de cada entrevista pendiente |
| Sección | Capítulo II — Entrevistas |
| Ruta esperada | `docs/tb1/assets/interviews/` |
| Contenido | Material que muestre el consentimiento, la entrevista o una transcripción revisable, sin datos privados innecesarios. |
| Información existente | Hay resúmenes de dos conductores y dos propietarios; no se publican enlaces que expongan identificadores de cuenta. |
| Información faltante | Una entrevista adicional de conductor y una de propietario, con consentimiento y evidencia de registro. |
| Herramienta recomendada | Grabadora autorizada y gestor de consentimiento; no generar con IA. |
| Prompt o brief | Documentar cada nueva entrevista con fecha, segmento, preguntas, respuestas verificadas y autorización de uso. |

## Prototipo o evidencia de landing page

| Campo | Detalle |
|---|---|
| Nombre | Prototipo de landing page y capturas de validación |
| Sección | Capítulo III — Evidencia de landing page |
| Ruta esperada | `docs/tb1/assets/landing-page/` |
| Contenido | Objetivo, audiencia, mensaje, pantallas, criterios de aceptación y evidencia de revisión. |
| Información existente | El alcance pide considerar una landing page. |
| Información faltante | Objetivo validado, contenido, diseño aprobado, implementación y resultados de prueba. |
| Herramienta recomendada | Figma para prototipo y navegador para capturas de una implementación validada. |
| Prompt o brief | Diseñar solo después de definir audiencia, propuesta, llamado a la acción, métricas y criterios de aceptación con el equipo. |

## User Journey Map con métricas de experiencia

| Campo | Detalle |
|---|---|
| Nombre | User Journey Map con puntos de contacto, emoción y métricas observadas |
| Sección | Capítulo II — Needfinding |
| Ruta esperada | `docs/tb1/assets/user-journey-map.svg` |
| Contenido | Recorrido por etapa con acciones, puntos de dolor y evidencias de investigación. |
| Información existente | Hay escenarios As-Is y To-Be descriptivos y cuatro resúmenes de entrevista. |
| Información faltante | Observaciones por etapa, evidencia de tareas y medición de emoción o esfuerzo. |
| Herramienta recomendada | FigJam, Miro o Figma después de completar la investigación. |
| Prompt o brief | Construir un mapa por segmento usando citas revisadas, pasos observados y métricas solo si fueron recolectadas. |
